# Prototype 0.1 / MVP

## 目的

Deep Factoryの中核である、

> 採掘 → 回収 → 売却 → 強化 → 最初の自動化

が3D空間で実際に遊んで成立するかを確認する。

## 必須機能

### プレイヤー

- 一人称視点
- WASD移動
- マウス視点操作
- 重力
- 地面・障害物との衝突
- 操作中のマウスロックと解除

### 採掘

- 採掘可能な岩
- 岩ごとの耐久値
- プレイヤーの採掘アクション
- 採掘クールダウンまたは採掘速度
- 岩破壊
- 鉱石ドロップ

### 鉱石

- 鉱石アイテム
- 取得
- 種類
- 数量
- 売却価格

MVPでは鉱石種類を増やしすぎず、2〜3種類程度に抑える。

### インベントリ

- 所持鉱石
- 最大容量
- 満杯時の処理
- HUD表示

### 売却

- 売却所
- 所持鉱石の売却
- 所持金増加
- 売却結果が分かるフィードバック

### アップグレード

最初は以下に限定する。

- 採掘速度
- 所持容量
- 移動速度

アップグレードはレベル、価格、効果量をデータとして分離する。

### 小型採掘機

- 購入
- 設置
- 設置可能 / 不可能の判定
- 一定時間ごとの資源生成
- 内部ストレージ
- プレイヤーによる回収

MVPではコンベア接続を実装しない。

### セーブ / ロード

最低限保存するもの:

- セーブ形式バージョン
- 所持金
- 所持鉱石
- アップグレード
- プレイヤー位置
- 設置済み採掘機
- 採掘機内部の資源

## MVP対象外

- コンベア
- 精錬
- 自動売却
- 研究ツリー
- 新エリア
- NPC
- 車両
- マルチプレイ
- ボス
- Prestige
- オフライン進行
- 実績
- 本格的なストーリー

## 完成条件

以下を、Godotエディタから起動した1つのプレイセッションで確認できること。

1. プレイヤーがマップを歩ける
2. 岩を採掘できる
3. 鉱石が出る
4. 鉱石を拾える
5. 売却できる
6. お金が増える
7. アップグレードを購入できる
8. 小型採掘機を購入・設置できる
9. 採掘機が自動生成する
10. 採掘機から回収できる
11. ゲームを終了して再起動しても保存状態を復元できる

これを満たした時点を **Prototype 0.1** とする。
